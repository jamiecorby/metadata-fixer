Questions

Do my photos get uploaded?

No. Reading and writing metadata happens in your browser using ExifTool compiled to WebAssembly. Only if you ask for an AI suggestion is a small, metadata-free copy of that one image sent to the AI, and it isn't stored.

Will it change my pictures?

No. Only metadata is changed; image and video data are left as they are. Your originals stay untouched: you save new copies.

What if a photo already has some metadata?

By default it only fills what's missing. Anything already in the file is kept unless you choose to overwrite it.

Does it handle time zones and daylight saving?

Yes. Times are written with the correct offset for the place and date, so photos sort correctly in Apple Photos and Google Photos.

What does Sanitise files do?

It is a separate mode (button at the top) that makes clean copies of photos and videos with embedded metadata removed: EXIF, GPS, dates, camera and software details, XMP, IPTC, comments, thumbnails and previews, rotation tags, colour profiles, Content Credentials manifests and data hidden after the end of the file. Image data is copied unchanged where possible; a file that needs its rotation or colours applied to the pixels is redrawn (and says so). Each result is read back and checked, and the report lists what was removed and what could not be inspected. It never claims that every possible hidden structure is gone: video encoders can leave text inside the video stream itself, which this cannot see. RAW files and GIFs are not supported. Nothing is uploaded, and Recover mode is untouched.

What does the Authenticity check do, and can I trust it?

Before export it reads each file's own evidence: Content Credentials (C2PA), the IPTC "digital source type", AI tool and prompt fields (Midjourney, DALL-E, Stable Diffusion, Firefly and others) and camera, lens and date combinations that cannot be right. It gives a 0-100 AI likelihood with a range, the evidence and plain suggestions. It is a heuristic, not proof: an image with no markers can still be AI-made, and a marked image can be genuine. Content Credentials are detected and read but their signatures are not validated here. An optional visual check (1 AI credit per file) can add a second opinion but can never be decisive. It only advises: nothing is blocked, and In Recover mode, Fix can add an accurate disclosure label or correct inconsistent metadata, but never removes or hides AI provenance. The separate Sanitise mode does the opposite on purpose: it removes embedded metadata, including Content Credentials, and says so in its report.

How accurate are AI suggestions?

They're estimates from what's visible: season, light, landmarks, signs. Each comes with a confidence and the reasons, and is never applied without your review.

    How values are chosen

    Values are applied automatically only when the evidence is strong: what is already in the file, Google Takeout sidecars, XMP sidecars and dated file names. Everything else (neighbouring files, your trip details, AI estimates, file modified times) is offered as a suggestion for you to pick.

    Statuses

    Needs info: no date yet. Review: changes planned, not yet accepted. Ready: accepted, will be exported. Done: written and verified. Complete: already had what it needs.
