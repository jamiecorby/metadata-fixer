# Metadata Fixer - UI/UX pass, 8 Nov 2026

Branch `ux-pass`. Harness: `tests/ux.py` (part of `npm test`). Screenshots at 1440x900, 390x844 and 320x640, light and dark, are produced with `SHOTS=<dir> python3 tests/ux.py`.

## Scope and method

Web app (static, in-browser). Roles: one (the person fixing a library); surfaces: desktop browser, iPhone Safari, no print or email. Jobs walked: add files, review one file, change trip details, open Settings and Help, Sanitise screen. Binding rules: none changed (no pricing, credit, auth or metadata-writing logic touched).

Brand source: no `lookbook_metadata-fixer` row exists in D1 `ventures_marketing` (look books exist for Virra, GapScore, LegaCasa, Scorchly, Kitty). The existing tokens in `src/styles.css` (teal accent, IBM Plex Sans/Mono, slate neutrals tinted toward the accent, light and dark) were treated as the design system. OQ-1: create a look book row for Metadata Fixer from the current tokens? Default: no, leave as is.

Direction phase: not run. Look scored 4, above the trigger of 3, and no redesign was asked for. Mobbin and Screenrove were not used: nothing in this pass imitates another product, so there are no precedents to cite.

## Findings and fixes

| # | Pri | Finding | Fix | Evidence |
|---|-----|---------|-----|----------|
| 1 | P1 | The landing and Sanitise drop zones were labels for a hidden input and could not be reached or used by keyboard (WCAG 2.1.1) | Drop zones are `role=button` with `tabindex=0`; Enter and Space open the chooser; focus ring added | Proven: harness failed on all widths |
| 2 | P1 | On phones the header wraps to two rows (c.98px) but the sticky toolbar was pinned at 55px, so the Add files / Add folder / Trip details row slid under the header | Header and bottom-bar heights are measured into `--hh` and `--bh`; toolbar, details pane and toast use them | Proven: screenshot `phone-dark-2-grid` before/after |
| 3 | P2 | Toast overlapped the bottom bar text on phones (fixed 84px offset against a c.190px bar) | Toast sits above the measured bar height | Proven: screenshot, harness overlap check |
| 4 | P2 | No skip link | "Skip to content" link, `main` is focus target (WCAG 2.4.1) | Proven |
| 5 | P2 | FAQ summaries 23px tall and checkbox rows 20px: below the 24px minimum of WCAG 2.2 target size (2.5.8) | Minimum 32px on fine pointers; footer links 32px | Proven: measured |
| 6 | P2 | iPhone targets 28-41px against the 44pt guideline | `(pointer: coarse)` raises buttons, inputs, selects, filter chips, checkbox rows, footer links, dialog close and previous/next to 44px | Supported: Apple HIG minimum hit target 44x44pt (recalled, unverified link) |
| 7 | P2 | Escape did not close the full-screen details sheet on phones | Escape closes the sheet and returns focus to the tile | Proven |
| 8 | P2 | Phone landing: the primary action (drop zone) started c.645px down, below the explainer text | On narrow screens: headline, drop zone, folder button, then explainer and ticks (Fitts, Hick) | Proven: screenshot |
| 9 | P3 | Desktop landing: large gap between the drop zone and "Choose a whole folder" | Both live in one column | Proven: screenshot |
| 10 | P3 | Video badge collided with the status pill on 108px tiles | Badge moved under the pill | Proven: screenshot |
| 11 | P3 | Page title 62 characters (truncated in tabs and results) | "Metadata Fixer - restore photo and video dates" | Proven |
| 12 | P3 | Map search field had an inline style and no accessible name | Class and `aria-label` | Proven |
| 13 | P3 | Reduced-motion rule covered transitions only | Also animations and smooth scrolling | Proven |

## Checks that passed without change

axe-core (WCAG 2.0/2.1/2.2 A and AA plus best practice) reports zero violations on every state: landing, loaded grid, details, Trip details, Settings, Help, Sanitise, in light and dark at all three widths. No horizontal scroll at 320px or at 200% zoom. Dialogs take focus, close on Escape and return focus. Visible focus on every tab stop.
